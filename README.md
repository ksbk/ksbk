## Selected projects

### Knowledge-Based Minesweeper AI

A Python knowledge-based AI agent for Minesweeper with an interface-independent

tests across the core modules.

- Repository: https://github.com/ksbk/knowledge-based-minesweeper-ai
- Case study: https://drkusse.com/projects/knowledge-based-minesweeper-ai

### Django Portfolio Platform

A production Django portfolio for publishing structured project case studies,
supporting project discovery, and handling contact submissions reliably. The
project uses Django server rendering as the baseline, with React enhancement for
project filtering and sorting.

- Repository: https://github.com/ksbk/portfolio
- Live site: https://drkusse.com
- Case study: https://drkusse.com/projects/django-portfolio-platform

### Constraint-Based Crossword Solver

A Python solver that models crossword generation as a constraint satisfaction
problem using node consistency, arc consistency, backtracking search, and
heuristics. This is presented as an AI/search learning project, not as a
commercial product.

- Case study: https://drkusse.com/projects/constraint-based-crossword-solver
